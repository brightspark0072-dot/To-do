# VYRON

A installable PWA to track your daily routine, build discipline and make a comeback.

- Daily checklist with ring progress, streaks and an end-of-day mood and note
- Add, edit and delete your daily routine tasks (Do and Avoid habits)
- One-time tasks for any single day
- Progress: 7-day bars, 35-day heatmap, per-habit consistency
- Works offline; data stays on your device (export and import a JSON backup in More)
